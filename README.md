# ZP3–GPX4 Extracellular Immune-Suppression Axis — Article 3

## Scope
Standalone code & data repository for **Article 3** of the ZP3–GPX4 extracellular immune-suppression axis project (migration of the *Cell* 2026 GPX4–ZP3 axis into neuro-oncology / glioblastoma). This repository contains **only** the analysis code, frozen result tables, and submission-grade figures for Article 3.

## Directory structure
- `article3/` — manuscript-specific analyses
  - `scripts/`  — analysis scripts
  - `results/`  — **frozen result tables** (numerical truth; do not edit by hand)
  - `figures/`  — submission-grade SVG figures
  - `reports/`  — audit / reference-verification reports
- `reviews/` — peer-review artifacts (Article 3 only)
- `shared/` — shared utilities (scripts, fetch, data) copied in for self-containment
- `LICENSE`, `requirements.txt`, `environment.yml`

## Reproducibility
Frozen tables under `article3/results/` are the source of truth. Regeneration scripts are in `article3/scripts/` and `shared/scripts/`. Per-script audit notes are embedded inline in the analysis scripts.

## Data Availability
- **Code:** https://github.com/ming13333/zp3-gpx4-article3 (this repository)
- **Archived snapshot (Zenodo DOI):** [10.5281/zenodo.22096075](https://doi.org/10.5281/zenodo.22096075)
- **Raw external datasets** (GSE113474, GSE77530, TCGA, cBioPortal, IMvigor210, GSE91061, etc.) are available from their respective public repositories; processed intermediates are regenerated by the provided scripts.
