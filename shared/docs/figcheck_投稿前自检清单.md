## 0. figcheck 机制速记（2026-08 据官网/公开资料核实）

- **Basic 模式**：在上传稿件范围内查重。**三篇稿件应一起打包上传**，才能识别跨篇重复对。
- **Deep 模式**：与已发表文献（PMC / bioRxiv / medRxiv / PubPeer）比对，能识别裁剪、翻转、旋转、缩放、改色后的复用图，**查全率≈98%**。
- **关键认知**：同一数据重新渲染成"不同布局 + 不同统计 + 不同坐标"的图，Basic 不报；但编辑审查层仍会追究数据冗余，故**靠铁律（唯一归属）规避，而非靠"改画法"躲查重**。

## 3. Supplement 边界红线（ICMJE 覆盖 main + supplement）

| 情形 | 合法性 | 回法 |
|---|---|---|
| 本文 supplement 放 **本文自己**扩展图 | ✅ 合法 | 该图未在他篇出现过即可 |
| 本文 supplement 放 **他篇已发表图** | ❌ 违规 | 冗余出版 + figcheck Deep 报警 |
| 编辑要求补充他篇结果 | ✅ 正确 | 引用他篇图号 + 本文 supplement 放**统计表格/数值**（非图像） |
| 两篇同期投稿（他篇未发表） | ⚠️ 披露 | 向编辑声明 companion paper，交叉引用，避免同图复用 |

**编辑要的是"证据"不是"抄图"**：用引用 + 数值表满足，不复制图像。

## 5. 投稿前 figcheck 运行步骤

1. 三篇稿件所有图导出 PNG/PDF（含 supplement）。
2. figcheck **Basic 三篇一起打包上传**（识别上传范围内所有重复对）。
3. 逐图对照 §1 三元组，确认无重叠。
4. 若任一篇已先发表 → 再跑 **Deep** 确认后投稿篇不与已发表篇撞图。
5. 任一疑似重复对 → 回 §1 重分配归属，删重复图，改交叉引用。
