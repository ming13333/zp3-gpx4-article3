# 神经 ZP3 生信研究 · DRIL 可复现审计与避坑指南

> 依据 ai-research-repro-guard 的 DRIL（Define→Execute→Verify→Archive）与 P1–P18 坑位，对本方案逐条审计。所有坑按 严重度(P0/P1/P2) · 静默症状 · 检测方法 · 纠错预案 · DRIL 门 五列结构化。

---

## 一、文献阶段坑

### P1 — 引用未核实 / 数字来自搜索摘要
- **严重度**：P1（高危）
- **症状**：正文引用"首个/空白/最优、88%、17 基因"等具体数字，但未回原始文本。
- **本方案处置**：RIS 库中每篇**关键锚点**均已回原始摘要核证（PMID 41494530/38125942/39039845/41664163/40684330/42148083/42225830/42497861）。"88% 肺癌表达 ZP3"已回到 PMID 39039845 原文。
- **纠错预案**：任何"首个/空白"结论前，用 PubMed DOI 精确反查 + 打开一手文本；无法回证的词一律标注"待核"。
- **DRIL 门**：人工抽查 10% 已纳入 + 10% 被排除文献，比对原文。

### P2 — 引用错配（把 A 论文结论安到 B 论文）
- **症状**：引文存在却不支撑所引句子。
- **本方案风险点**：CVT 的 ZP3（PMID 40684330）是 eQTL"名义显著"，**不可作为"ZP3 在脑中表达"的机制背书**——已明确降级为"线索引用"。
- **DRIL 门**：写作时每引用一句回查 DOI 对应摘要。

## 二、数据库阶段坑

### P3 — 版本混淆 / 数据漂移（version drift）
- **严重度**：P2
- **症状**：TCGA/GEO/GTEx 重新拉取元数据/注释变化；同一 accession 两次结果不同。
- **本方案处置**：数据底座表列"数据集 + 版本 + 下载日期"，强制记录；CGGA/GTEx/TCGA 均写构建版本。
- **纠错预案**：冻结 accession + 捕获清单日期；脚本开头 print 版本哈希。
- **DRIL 门**：每次分析前 diff 当前环境与 archived 环境。

### P4 — 概念标签泄漏（标签构建含结局）
- **严重度**：P1（中枢特有高危）
- **症状**：把"ZP3-Cancer 富集"标签与"免疫逃逸/预后"标签在同一样本切分中反复交叉验证，形成圆形推理（P7）。
- **本方案处置**：H2/H3 用**bulk 独立队列**做生存/浸润关联；单细胞仅做**细胞型别内** ZP3+ 比例，不做"ZP3 高 vs 低"在同一矩阵里既聚类又推断功能。
- **DRIL 门**：变量构建代码逐行审 + 独立简化查询复现。

### P5 — 患者级 vs 片段级泄漏（伪重复）
- **严重度**：P1（单细胞特有高危）
- **症状**：同一患者多个细胞 / 同一 donor 多个片段被当作独立样本，夸大自由度、缩小 SE；**跨图谱合并时尤其隐蔽**。
- **本方案处置**：单细胞统计以 **patient/donor 为聚类单元**（pseudobulk 或混合效应），报告 donor 数而非 cell 数；多图谱合并前做 donor 效应去批次。
- **DRIL 门**：核验每个公开图谱的 donor→样本映射表；pseudobulk 复算关键聚类。

### P6 — n 静默漂移
- **症状**：写 n=500 实际 487；下载失败被静默跳过。
- **本方案处置**：下载/过滤每步输出计数并核对；任何失败**停止并报告**，不跳过。
- **DRIL 门**：每条 pipeline 输出现有 n vs 期望 n。

## 三、分析阶段坑

### P7 — 概念瓶颈圆形推理（在定义同一信号的细胞上宣称该信号功能）
- **本方案关联**：不用"ZP3 高 TME 本就免疫抑制"去"证明 ZP3 致免疫抑制"。
- **纠错预案**：关联独立标志物（CD8A/PDCD1/糖酵解基因）与**外部** CD8 浸润工具交叉验证。
- **DRIL 门**：多方法（CIBERSORTx+MCPcounter+quanTIseq）共识，不单点依赖。

### P8 — 归属错配（用不匹配模型/工具解构转录本）
- **本方案关联**：ZP3-Cancer（缺信号肽转录本）探针/注释必须用**转录本水平**（Salmon/kallisto），**不能用基因水平 count 代替**，否则 ZP3-Cancer 与经典 ZP3 无法区分。
- **DRIL 门**：转录本量化代码抽查；报告两种转录本各自的 TPM。

### P9 — 工具实现差异（不同反卷积库偏倚）
- **本方案**：见 P7 多方法共识。

### P10 — 忠实性/效应区域未定义
- **本方案关联**：配–受体共定位（GPX4↔ZP3）的"共定位区域"须**预先定义**（同一 niche/spot 邻域阈值），否则任意空间噪声都可叫共定位。
- **DRIL 门**：共定位阈值写入代码冻结；输出效应量 + 置乱对照（spatial permutation test）确认非随机。

### P11 — 批次效应未充分校正
- **本方案**：跨图谱/跨平台合并前 Combat/单细胞去批次；报告合并前后免疫细胞占比稳定性。
- **DRIL 门**：可视化 UMAP 前/后；差异由 donor 或 batch 驱动的检查（如 scCODA/包络核验）。

### P15 — 随机种子 / 环境未锁定
- **严重度**：P1
- **本方案处置**：单细胞聚类、切分、Cox cut-off 全设固定 seed；环境用 conda env 记录所有版本。
- **DRIL 门**：两次独立 seed 复跑关键指标一致。

### P16 — 数字/统计误读（HR/截断点过拟合）
- **本方案**：生存 cut-off 用 X-tile 但**必须在 CGGA/GEO 外部验证**，否则 overfit。多变量 Cox 校正 IDH/级别/MGMT/年龄。

## 四、写作阶段坑

### P17 — 范围膨胀
- **本方案**：已严格分层 primary（成人胶质瘤）/ secondary-exploratory（脑转移/髓母）；不在无验证亚组声称泛化。
- **纠错**：每个"预后相关"结论标注人群范围。

### P18 — AI 工具披露缺失
- **本方案**：末版在手稿 Methods/致谢写入 AI 检索与初筛工具 + 日期 + 复核声明（见主方案第 7 节）。
- **DRIL 门**：投稿前 checklist 勾选 AI 披露。
