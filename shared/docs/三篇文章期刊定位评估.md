## 〇、总体结论（来自记忆固化决策）

## 一、Article 1（主文）— ZP3 与免疫抑制性 TME 关联

**证据强度**：多队列（TCGA GBM/LGG、CGGA-325/693、IMvigor210、跨癌种单细胞、HPA），经 ai-research-repro-guard 全流程审计，13/16 图数值完全可复现，图注/数值已定稿。

**最大短板**：
- 完全依赖二次公共数据，无独立临床样本/组织验证；
- 无体外/动物/功能实验，"免疫抑制性 TME"目前为相关性证据；
- CGGA 中预后关联经 IDH、Grade、1p/19q 调整后不再显著（单变量 HR=1.236 → 多变量 HR=1.094, p=0.070），**不可称"独立预后因子"**；
- 机制仍为推断，不能写成因果机制。

**现实期刊档次**：**IF 4–6**（约）。

| 梯队 | 期刊 | 适配度 / 风险 |
|---|---|---|
| 冲刺 | Cancer Immunology, Immunotherapy（IF≈5.8） | 主题高匹配；但纯数据库缺实验验证，编辑可能以"机制深度不足"拒 |
| 冲刺 | npj Precision Oncology | 影响力高；当前缺临床样本/功能验证，直接命中概率低，**宜作"补验证后冲刺"目标** |
| 现实首选 | Computational and Systems Oncology（CiteScore≈4.6） | 与多队列计算肿瘤学/肿瘤免疫高度匹配，最现实 |
| 现实 | Scientific Reports（IF≈4.9） | 重技术可靠+可复现，不唯影响力；规范写、限制说明充分则现实性好 |
| 现实 | BioData Mining | 需把文章强化为"多队列计算框架/可复用方法"才最匹配 |
| 保底（慎） | BMC Cancer（IF≈4.1） | 官方声明**仅公共库生信、无验证的稿件不予考虑**；当前不列首选，除非补独立验证 |

**一句话**：已不像普通"单基因泛癌生信"，但更接近一篇**经严格审计的多队列计算肿瘤免疫研究**，而非机制型转化论文。不补实验时，最稳妥定位 **IF 4–6 领域期刊**；冲 IF 8+ 需补实验/独立临床验证。

## 二、Article 2（阴性结果）— ZP3 不预测 ICI 治疗反应

**证据强度**：多队列（GSE78220 n=28、IMvigor210 n=298 evaluable、GSE91061 n=105 valid + 亚型/TMB 分层），诚实报告无关联；GSE91061 未校正时显著、控制免疫特征/分子亚型后消失，支撑"旁观者标志物"。

**最大短板**：
- 纯阴性/无效结果，多数 IF 期刊会 desk-reject 无机制深度的 null finding；
- 科学"增量"在于多队列一致性 + 主动发表阴性结果（规避选择性报告），而非新发现。

**现实期刊档次**：**IF 2.5–4.5**（约）。

| 梯队 | 期刊 | 适配度 / 风险 |
|---|---|---|
| 首选 | PLoS ONE（IF≈3.7） | 明确欢迎确证/阴性/重复结果；最稳 |
| 首选 | Scientific Reports（IF≈4.9） | 可复现阴性基准可投；需透明方法 |
| 首选 | F1000Research / Wellcome Open Research | 开放式同行评审，收阴性/方法基准 |
| 对冲 | BMC Cancer（IF≈4.1） | 需核对其阴性结果政策；若仅写"阴性"易被拒 |
| 包装建议 | 作为"多队列基准/警示证据"（against over-interpreting single-gene ICI biomarkers）而非纯阴性 | 显著降低 desk-reject 率 |

**一句话**：A2 是"最先投但潜力最低"——稳但天花板低。核心卖点不是发现，而是**多队列诚实阴性 + 方法学透明**；须包装为"基准/警示"而非单纯"无关联"。

## 三、Article 3（异构体方法学）— ZP3 isoform / TRA 代理 PSI

**证据强度**：三层证据互咬合——样本级 FL-PSI×免疫 ρ=0.13–0.54（方向全正）、癌种级生态学 ρ=+0.952 (p=2.6e-4)、Mixed-effects（FL 固定效应 6/7 显著正、RI 6/7 显著负）+ GSEA（FL_high 富集 TNF-α/NF-κB）。

**最大短板**：
- 样本级关联中等（未达 0.7），方法卖点依赖"TRA 代理 PSI"诚实边界；
- 若仅包装为 ZP3 特异性发现而非**可复用方法**，天花板下降。

**现实期刊档次**：**IF 4–6**（若包装为可复用方法可上探）。

| 梯队 | 期刊 | 适配度 / 风险 |
|---|---|---|
| 冲刺 | Bioinformatics（IF≈5–6） | 方法/工具类高匹配；但竞争激烈，需方法新颖+可复用 |
| 现实 | BMC Bioinformatics / BMC Genomics | 方法学/组学创新匹配 |
| 现实 | BioData Mining | 可强化为计算方法贡献 |
| 现实 | Scientific Reports | 通用兜底 |
| 保底 | Genes / 专科组学刊 | IF 较低但易中 |

**一句话**：A3 潜力最高。卖点=**癌种级验证 ρ=0.952 + Mixed 加固 + GSEA 暗示 + 三层证据互咬合**；须把"TRA 代理 PSI"方法学诚实边界写清（样本级未达 0.7），并以可复用方法而非单一基因发现来定位。

## 四、通用升级路径（补实验/临床验证后上探）

若补充以下任一项，期刊档次可整体上探：
- 独立脑胶质瘤组织中 ZP3/TREM2 共定位（空间/免疫荧光）；
- 蛋白层面验证（ELISA/IHC）；
- ZP3 对髓系细胞或免疫抑制表型的功能实验（体外/动物）；
- 独立临床队列验证。

补验证后，A1/A3 可重新考虑 **npj Precision Oncology、Cancer Immunology, Immunotherapy 甚至更高层级**；三篇合并方案（claim 降级为"共变/TRA 代理"）在记忆中记为"期刊降至 Neuro-Oncology 档"的合并假设（**非当前拆分状态**）。
